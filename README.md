# User Input & Data Type Detection (Python)
## 📝 Description

This project demonstrates basic Python programs for handling user input and detecting data types. It helps beginners understand how to:

Read input from users.

Convert input to different data types (int, float, str).

Detect the type of a given value automatically.

## 📌 Project Overview

This project includes two small Python scripts:

✔ User Input → Reads a number from the user and prints it.

✔ Data Type Detection → Determines if the given input is an int, float, or str.

## 📂 Files

userinput.py → Reads a number (integer) from the user and prints it.

datatypt.py → Accepts any input and identifies whether it is an integer, float, or string.

## 🔑 Key Features

Demonstrates Python’s input() function.

Uses try-except to safely detect data types.

Simple, beginner-friendly code with clear output.

## ▶ Example Runs

userinput.py

Input: 7

Output: 7

Input: -5

Output: -5


datatypt.py

Input: 42

Output: Value: 42, Type: int

Input: 3.14

Output: Value: 3.14, Type: float

Input: Hello

Output: Value: Hello, Type: str

## 📦 Requirements

No external libraries required.

Just make sure Python 3 is installed:

python --version

## 🚀 Run the Programs

Open terminal in the project folder.

Run the script:

python userinput.py


or

python datatypt.py
